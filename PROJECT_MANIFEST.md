# Архитектурный Манифест Проекта (Project Manifest)
## Спецификация дизайна и взаимодействия: Urban Glass Dance Studio App

Данный документ представляет собой техническое руководство и источник правды для разработчиков и архитекторов, описывающий архитектуру клиентской части, дизайн-систему, навигацию и анимационные сценарии приложения Urban Glass.

---

## 1. Стек технологий и управление состоянием (Tech Stack & State)

*   **Фронтенд-фреймворк:** React 18+ (сборщик Vite, среда TypeScript).
*   **Роутинг:** `wouter` — легковесный клиентский роутер. Архитектура маршрутизации построена на декларативных компонентах `<Switch>` и `<Route>` без лишней вложенности контекстов.
*   **Связь с базой данных и авторизация:** Клиентская интеграция с **Supabase SDK**. Состояние сессии отслеживается через стандартный React-стейт и синхронизируется через методы `supabase.auth.getSession()` и `supabase.auth.onAuthStateChange()`.
*   **Локальное состояние UI:**
    *   Активные разделы навигации определяются через хук `useLocation()` из `wouter`.
    *   Персональные настройки темы и уведомлений сохраняются в `localStorage` (`settings_push_enabled`, `settings_reminders_enabled`, `app-accent-color`).
    *   Синхронизация выбранных акцентных цветов происходит через обновление CSS-переменных на корневом уровне DOM (`document.documentElement.style.setProperty('--primary', colorValue)`).

---

## 2. Токены дизайн-системы (Design System Tokens)

Интерфейс выполнен в премиальной темной теме **Urban Glass** с ярким неоновым акцентом, вдохновленной стилем киберпанка и современной городской архитектуры.

*   **Цвет холста (Canvas Background):** Глубокий чистый темный цвет `#09090b` (`bg-[#09090b]`).
*   **Стеклянные контейнеры (Glassmorphic Cards):** Полупрозрачные плашки `#18181b` (`bg-[#18181b]` или `bg-zinc-900/60`) с эффектом размытия заднего плана `backdrop-blur-md` и тонкой контрастной рамкой `border-zinc-800/80` (или `border-zinc-800/85`).
*   **Фирменный акцент (Primary Accent):** Ультра-яркий неоново-лаймовый цвет `#CCFF00` (`text-[#CCFF00]`, `bg-[#CCFF00]`, `shadow-[#CCFF00]/10`).
*   **Кастомизация акцентов:** Пользователь может изменить цвет акцентов в настройках. Доступные токены:
    *   Лайм: `#CCFF00`
    *   Голубой: `#00F0FF`
    *   Розовый: `#FF007F`
    *   Оранжевый: `#FF5E00`
    *   Фиолетовый: `#A100FF`
*   **Скругления и геометрия:** Минимизация визуального шума сетки за счет использования идеальных капсул `rounded-full` для интерактивных переключателей, кнопок и вкладок. Для карточек используются скругления `rounded-[24px]` или `rounded-t-[28px]`.

## 3. Структура навигации (Navigation Structure)

### Клиентские разделы (Client Views)
1.  **Главный экран (`/` -> `Home.tsx`):**
    *   Счетчик времени до следующего занятия.
    *   Интерактивный промо-баннер **NewsBanner** с выезжающей панелью деталей.
    *   Раздел записи на тренировки.
    *   Шторка центра уведомлений.
2.  **Расписание (`/schedule` -> `Schedule.tsx`):**
    *   Интерактивный календарь с фильтрацией тренировок по направлениям.
    *   Детали классов с возможностью быстрой записи.
3.  **Профиль (`/profile` -> `Profile.tsx`):**
    *   Интерактивная карта абонементов (поддержка выдвижной шторки подробностей).
    *   История посещенных и предстоящих занятий.
    *   Система обратной связи и оценки тренера/занятия.
4.  **Настройки (`/settings` -> `Settings.tsx`):**
    *   Смена аватара (с локальным FileReader-превью и базовым Base64-сохранением в БД).
    *   Поля изменения имени и контактного телефона.
    *   Интерактивные iOS-style переключатели Push-уведомлений и напоминаний.
    *   Палитра выбора акцентного цвета.
    *   Системная информация (версия приложения, статус API).
    *   Кнопка выхода из аккаунта.

### Нижний док навигации (`BottomNav.tsx`)
*   **Позиционирование:** Зафиксирован на `fixed bottom-6 left-1/2 -translate-x-1/2 z-[85]`.
*   **Габариты:** Равномерное адаптивное распределение кнопок (`w-[90%] max-w-[400px]`).
*   **Состав элементов (клиент):** Главная, Расписание, Профиль, Настройки.

## 4. Реестр механик компонентов (Component Mechanics Registry)

### А. Механика выдвижной панели (Bottom Sheet / Drawer)
Механика открытия подробной информации (используемая для абонементов в `Profile.tsx` и акций в `NewsBanner.tsx`) разработана с использованием `AnimatePresence` и пружинной физики от `framer-motion`.

```tsx
// 1. Управление состоянием открытия шторки
const [isOpen, setIsOpen] = useState(false);

// 2. Декларативная верстка шторки
<AnimatePresence>
  {isOpen && (
    <>
      {/* Затемняющая подложка (Backdrop Overlay) */}
      <motion.div
        initial={{ opacity: 0 }}
        animate={{ opacity: 1 }}
        exit={{ opacity: 0 }}
        onClick={() => setIsOpen(false)}
        className="fixed inset-0 bg-black/85 backdrop-blur-md z-50 cursor-pointer"
      />

      {/* Панель (Bottom Sheet Container) */}
      <motion.div
        initial={{ y: "100%" }}
        animate={{ y: 0 }}
        exit={{ y: "100%" }}
        transition={{ type: "spring", damping: 25, stiffness: 220 }}
        className="fixed bottom-0 left-0 right-0 bg-[#121214] border-t border-zinc-800/80 rounded-t-[28px] max-h-[85dvh] flex flex-col z-50 shadow-2xl overflow-hidden"
      >
        {/* Ручка свайпа / Стак индикатор */}
        <div className="w-12 h-1.5 bg-zinc-700/60 rounded-full mx-auto mt-3 mb-2 shrink-0" />
        
        {/* Содержимое шторки со скроллом */}
        <div className="px-6 py-6 overflow-y-auto scrollbar-none pb-36 space-y-6 flex-1">
          {/* Контент шторки */}
        </div>
      </motion.div>
    </>
  )}
</AnimatePresence>
```

**Технические параметры анимации:**
*   **Backdrop:** Вход и выход через плавное изменение прозрачности (`initial={{ opacity: 0 }}`, `animate={{ opacity: 1 }}`).
*   **Выдвижная панель:** Движение по оси Y (`y: "100%"` -> `y: 0`).
*   **Параметры пружины (Spring Transition):** `type: "spring"`, `damping: 25`, `stiffness: 220`. Идеальный физический отскок без лишнего покачивания.

### Б. Фирменный микро-отклик при нажатии (Haptic Press)
Каждая интерактивная карточка-триггер и кнопка используют пружинное сжатие при тапе:
```tsx
<motion.div
  whileTap={{ scale: 0.97 }}
  onClick={() => setIsOpen(true)}
  className="cursor-pointer"
>
  {/* Карта */}
</motion.div>
```

### В. Связанные переходы элементов (Shared Element Transitions)
Сглаженные переходы активных вкладок в нижнем навигационном меню (`BottomNav.tsx`) используют уникальный `layoutId` во `framer-motion`:
*   **Клиентские вкладки:** `<motion.div layoutId="activeTabGlowClient" ... />`
*   **Административные вкладки:** `<motion.div layoutId="activeTabGlowAdmin" ... />`
*   **Физика перемещения индикатора:** `transition={{ type: "spring", stiffness: 400, damping: 28 }}`. При переключении вкладок неоновая светящаяся капсула физически "перетекает" от одной кнопки к другой.

## 5. Дерево файлов и ключевые компоненты

```bash
/client/src/
├── App.tsx                 # Точка роутинга, конфигурация путей и вложенных видов
├── main.tsx                # Инициализация React DOM
├── index.css               # Импорт шрифтов, стилей Tailwind и глобальных CSS-переменных
├── components/
│   ├── BottomNav.tsx       # Нижний адаптивный док-навигатор (Клиент + Админ)
│   ├── ManagementMenu.tsx  # Высплывающий стеклянный оверлей разделов администрирования
│   └── NewsBanner.tsx      # Компонент акционного баннера с Bottom Sheet подробностями
└── pages/
    ├── Home.tsx            # Главный экран (Countdown, Сетка тренировок, Уведомления)
    ├── Profile.tsx         # Профиль ученика (Статистика, Абонементы, Обратная связь)
    ├── Settings.tsx        # Новый экран настроек, кастомизации цвета и PWA данных
    ├── Schedule.tsx        # Календарь занятий и запись
    └── Admin.tsx           # Основная панель администрирования
```

Данная архитектура гарантирует безупречную производительность анимаций с частотой кадров до 120 Гц на мобильных экранах, создавая ощущение нативного мобильного приложения за счет оптимизации структуры рендеринга и z-index разметки.
